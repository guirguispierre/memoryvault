Questions

Is it really fully open source?
Yes — MIT licensed, graph and all. There's no paywalled tier of the software itself; the only thing you'd ever pay for is optional managed hosting.
Where does my data live?
In your own Cloudflare account — your D1 database and Vectorize index, under your keys. If you self-host, your memories never touch our infrastructure.
Which agents does it work with?
Anything that speaks MCP — Claude, Claude Code, Codex, and custom agents — plus a plain REST API for everything else.
How is it different from other memory tools?
Graph-aware and open with nothing paywalled, self-hosted so you own the data, and tenant isolation that's covered by an adversarial test suite rather than asserted in a blog post.
